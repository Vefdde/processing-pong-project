# Pong-Spiel (Softwareentwicklung Projekt)

Ein klassisches Pong-Spiel, entwickelt im Rahmen des SEW-Unterrichts in der 1. Klasse HTL Rennweg. 
Projektpartner: Philipp Ye & Benjamin Velagic.

## Spielmodi
Das Spiel enthält ein Hauptmenü mit zwei Modi:
- **Einzelspieler:** Spiele gegen einen KI-Gegner (Bot).
- **Mehrspieler:** Spiele lokal zu zweit an einer Tastatur.

## Steuerung
- **Spieler 1 (linker Schläger):** 
  - Nach oben: `W`
  - Nach unten: `S`
- **Spieler 2 / Bot (rechter Schläger - im Mehrspieler):** 
  - Nach oben: `Pfeiltaste Oben`
  - Nach unten: `Pfeiltaste Unten`
- **Menü / Zurück:** Klick auf den Escape-Button auf dem Bildschirm.

## Verwendete Technologien
- **Processing** (Java-basierte Programmierumgebung)
